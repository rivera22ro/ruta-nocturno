# Rueda Nocturna

Landing de la campaña de rutas nocturnas en bici por Medellín, creada para Rueda Libre.

**Demo:** [URL de GitHub Pages]
**Sitio principal:** [URL de Rueda Libre]

## Páginas
- `index.html`: landing completa (inicio, rutas, planes, cómo funciona, inscripción).
- `componentes.html`: kit de componentes (botones, card, alertas, campos).
- `prototipo.html`: prototipo inicial con Play CDN.

## Tecnologías
HTML5 · Tailwind CSS v4 (CLI) · Google Fonts (Montserrat, Open Sans)
